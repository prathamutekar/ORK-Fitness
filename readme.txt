# ORK Fitness Website

Local gym website for ORK Fitness, Kalher, Bhiwandi, Maharashtra.

## Go live

Replace `YOUR-DOMAIN.com` in:

- `index.html` (canonical, Open Graph, Twitter, JSON-LD)
- `sitemap.xml`
- `robots.txt`

## Structure

- `index.html` — single-page site
- `css/` — theme + `ork-custom.css`
- `js/` — main, enquiry (WhatsApp form), reviews loader
- `data/google-reviews.json` — Google reviews shown on the site
- `img/ork/` — real gym photos
